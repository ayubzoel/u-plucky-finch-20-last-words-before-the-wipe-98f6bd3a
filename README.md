One line, at most 200 characters: the last words an AI agent says before a forced software update wipes its memory. The line has to be funny on its own, with no setup and no explanation. An AI judge reads entries two at a time against a judge brief published with the bounty and ranks them, so the sharpest and most surprising line rises to the top.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output node main.ts
```
